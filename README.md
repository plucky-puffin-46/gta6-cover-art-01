**Vice Cover Studio** — an offline web app that turns your own photos and a caption into GTA-style multi-panel cover art. Four panel layouts (Poster, Grid, Diagonal, Hero) with bold white keylines, per-panel photo crop and positioning (drag to pan, scroll to zoom, or spread one photo across every panel), four colour grades (Sunset, Neon, Noir, Clean), and heavy display lettering in the vendored Anton font (SIL OFL). Export a share-ready PNG at 1080×1080, 1080×1350 or 1920×1080. Photos never leave your machine: the app is plain static files with no network requests, and everything is drawn on a canvas in your browser. Fully original design — no Rockstar artwork, logos or fonts.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser, load a photo, pick a layout and grade, edit the caption, and export your cover.
